CR3 → JPEG для Windows 11
===========================

Программа конвертирует файлы Canon RAW (.CR3) в JPEG.
Исходники не удаляются и не изменяются.

КАК ПОЛУЧИТЬ EXE НА WINDOWS 11
1. Установите Python 3.12 (64-bit) с https://www.python.org/downloads/
   При установке отметьте «Add python.exe to PATH».
2. Распакуйте этот архив в любую папку.
3. Дважды щёлкните build_windows.bat (нужен интернет для установки библиотек).
4. Готовый файл находится в dist\CR3_to_JPEG.exe.
5. EXE можно перенести на другой ПК Windows 11 без Python.

АЛЬТЕРНАТИВА (без локальной установки Python):
Создайте GitHub-репозиторий, загрузите туда содержимое архива
(включая .github/workflows/windows-exe.yml), откройте Actions >
Build Windows EXE > Run workflow. После сборки скачайте артефакт
CR3_to_JPEG_Windows_11 с готовым EXE.

КАК РАБОТАТЬ
- Добавьте CR3-файлы или выберите папку с фотографиями.
- Выберите папку для сохранения JPEG.
- Выберите качество (обычно 95).
- Нажмите «Конвертировать в JPEG».
- Можно остановить обработку после текущего файла.

ВАЖНО
- Используется LibRaw (rawpy), автоматическая обработка RAW и цветовое
  пространство sRGB, баланс белого — из настроек камеры.
- JPEG не сохраняет весь динамический диапазон и гибкость редактирования RAW.
- Существующие JPEG не перезаписываются: к имени добавится _1, _2 и т. д.
- Если RAW-файл конкретной новой камеры не поддерживается LibRaw,
  программа запишет ошибку в cr3_conversion_errors.txt.
- EXIF-метаданные из CR3 в данном выпуске не переносятся.
- «Запустить» на Windows может показать предупреждение SmartScreen,
  поскольку самостоятельно собранный EXE не подписан сертификатом.
